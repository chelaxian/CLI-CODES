# providers.txt -- реестр провайдеров моделей (OpenAI-совместимые API).
#
# Формат (разделитель |, пустое поле = "-"):
#   key | name | get-key-url | env-var | base-url | models-url | auth | tier | anthropic-url | responses | note
#
# key            -- канонический ключ (имя файла статического каталога TXT/models/<key>.txt)
# env-var        -- переменная окружения с ключом (хранится в ~/.config/cli-codes/keys.env
#                   на Linux/macOS и в пользовательских переменных среды на Windows)
# base-url       -- OpenAI-совместимый base URL (без /chat/completions)
# models-url     -- откуда динамически брать список моделей:
#                     -     = <base-url>/models
#                     none  = только статический каталог TXT/models/<key>.txt
#                     <url> = свой адрес (например, публичный каталог)
# auth           -- key (ключ обязателен) | optional (работает и без ключа) | none (локальный сервер)
# tier           -- free (бесплатно) | freemium (бесплатная квота/лимиты) | paid | local
# anthropic-url  -- нативный Anthropic-совместимый endpoint (для Claude Code без прокси), "-" если нет
# responses      -- yes, если есть OpenAI Responses API (нужно для Codex CLI)
#
# Первые 4 колонки совместимы со старым форматом (scripts/launcher-text-resolver.ps1).
# Порядок строк = порядок в меню: сначала бесплатные/с бесплатной квотой.
